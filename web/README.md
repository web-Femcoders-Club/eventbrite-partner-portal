# Eventbrite Partner Portal - Web Frontend

## 🎨 Descripción

Interfaz premium el portal de partners, diseñada para ofrecer una experiencia fluida y profesional.

## 🛠️ Tecnologías

- React 19
- Vite
- Tailwind CSS v4
- TypeScript (Strict Mode)

## ♿ Accesibilidad y SEO

- Cumplimiento **WCAG AA/AAA**.
- HTML5 Semántico.
- Optimización de Core Web Vitals.

## 🏁 Inicio Rápido

1. `npm install`
2. `npm run dev`
