# Eventbrite Partner Portal - Backend API

## 🚀 Descripción

Servicio encargado de gestionar la lógica de negocio, integración con Eventbrite y gestión de partners.

## 🛠️ Tecnologías

- Node.js v20+
- Express
- TypeScript
- (Añadir DB cuando se defina)

## 🏗️ Arquitectura

Sigue principios de **Clean Architecture** y **SOLID**.
Ver detalles en [architecture.md](./architecture.md).

## 🔒 Seguridad y Cumplimiento

- **RGPD/LOPD**: Implementado sistema de logs anonimizados y gestión de consentimiento.
- **AI Act**: Documentación de modelos y transparencia de datos.
- **Validación**: Uso de `Zod` o `Joi` para esquema de datos.

## 🏁 Inicio Rápido

1. `npm install`
2. `npm run dev`
